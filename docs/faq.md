# 常见问题

## 安装 / 启动

**Q：`install.sh` 卡在拉基础镜像 / 报 Bad Gateway？**
Docker Hub 偶发抖动，重跑 `./install.sh` 即可。持续失败说明网络需要代理或镜像加速。

**Q：预置管理员后启动失败？**
用户名必须 2~30 字、密码至少 6 位，不满足会在自动建号时校验失败、服务起不来（有意设计）。修好 `.env` 后重新 `./install.sh`。

**Q：忘了管理员密码？**
两种办法：
1. 有另一个管理员账号 → 让他登录，停用旧账号、新建一个；
2. 只有一个管理员 → 需要直接操作数据库重置（`user_row` 集合里该用户的 `password` 字段换成新密码的 bcrypt 哈希）。停用成员同理。

**Q：为什么浏览器一直跳到 `#/setup`？**
系统未初始化（空库）。要么在向导里注册管理员，要么在 `.env` 预置后重启。已完成初始化却仍跳转，检查 Mongo 数据卷是否被误删（`docker volume ls`）。

**Q：打开网页 502 / 一直转圈？**
```bash
docker compose ps                 # 应全部 healthy
docker compose logs app --tail 50 # 看后端报错
```
常见原因：端口被占用、`data/` 目录所在磁盘没挂载。

## 使用

**Q：成员和管理员有什么区别？**
成员只能删/改自己的帖子和评论；管理员可以删任何内容、改话题名、删话题、进管理端。新用户由管理员在管理端添加，注册接口不对公众开放。

**Q：停用成员后他的帖子还在吗？**
在。停用只封账号并清登录状态，帖子、评论、头像全保留。想连内容一起删，需手动删帖。

**Q：上传的图片被压缩了吗？视频呢？**
图片：原图保留，同时生成 webp 缩略图（浏览时按需加载，老设备也快）。视频（mp4）：**不压缩**，原样落盘。

**Q：分享链接能免登录看多久？**
分享链接本身长期有效，免登录可见的内容由「开放话题」设置决定（话题管理里配置）。

## 运维

**Q：备份开关打开了，为什么目录里没有文件？**
任务每天 **0:00** 才执行（按 `.env` 的 `TZ`），刚打开要等次日。想立刻验证可看容器日志确认任务注册：`docker compose logs app | grep jobRegistry`。

**Q：清理任务会不会误删我的图片？**
不会物理删。无引用文件只是移到 `data/uploads/_trash/`，发现误判直接移回来即可。被任何帖子/评论/话题背景/头像引用的文件永远不会动。

**Q：`_trash` 里的文件会自动清掉吗？**
不会。清理由你手动决定，确认不需要了直接删 `_trash` 目录内容。

**Q：改了 `UPLOADS_DIR` 路径后老图打不开？**
把旧目录的文件全部拷到新路径再重启即可，数据库里存的是文件名，不带路径。

**Q：想换一台机器整体迁移？**
看 [backup-restore.md](backup-restore.md) 的「恢复到新机器」一节，记住口诀：**JSON 备份 + uploads 目录，两个一起带走**。

**Q：磁盘快满了，哪里占的空间？**
依次检查：`data/uploads`（原图/视频，大头）、`data/uploads/compress`（缩略图，很小）、`data/backups`（最多 7 份 JSON，很小）、`docker system df`（镜像与卷）。视频不压缩，空间主要取决于发了多少视频。

**Q：启动时报 `container wink-mongo-1 is unhealthy` / 日志里一堆 `SCRAM authentication failed`？**
数据卷已用**旧密码**初始化，与 `.env` 里的 `MONGO_PASSWORD` 不匹配。`MONGO_INITDB_*` 只在数据卷**首次空卷建库**时生效，之后改 `.env` 不会同步到库内用户（这也是 `.env` 里提醒「初始化过数据卷后不要再改凭据」的原因）。两种处理：
- 保留数据：用旧密码进容器把用户密码改回 `.env` 里的值（`mongosh -u wink --authenticationDatabase admin` → `db.updateUser("wink", {pwd: "新密码"})`）；
- 清空重建（丢库内全部数据）：`docker compose down -v && ./install.sh`。
`./install.sh` 现在会自动识别这种场景并直接给出上述指引，不再傻等健康检查超时。
